# Arshan Nekoui

My personal portfolio website. 'Receipts not resumes' as I like to call it.

Feel free to contact me if you have any suggestions or issues.

## Run locally

Static site with no build, so any static server will work! :)

```bash
# python
python3 -m http.server 8777

# or node
npx serve .
```

Then open whatever localhost port is prompted in your terminal.
